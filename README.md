# Pizzaria — Landing Page

A single-page, neo-brutalist pizza shop site.
Built with HTML, Tailwind CSS (CDN), JavaScript, GSAP, and ScrollTrigger.

**Live site:** https://YOUR-USERNAME.github.io/pizzaria-landing/

---

## Design system

**60-30-10 palette**
- 60% Cream `#FDF6E3` (dominant)
- 30% Charcoal `#1F1B16` (secondary)
- 10% Tomato `#E63946` (accent)
- Basil `#2A9D8F` for focus rings

**Style:** Neo-brutalism — bold borders, hard shadows, chunky buttons.

**Contrast:** Charcoal on cream = 14.7:1 (passes WCAG AA).
